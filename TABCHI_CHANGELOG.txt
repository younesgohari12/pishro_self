v0.08 — Message Font Panel
--------------------------
- Added top-level «🔤 فونت» button to .پنل.
- Added per-user message_font_enabled and message_font_style settings.
- Added six native Telegram formatting styles: bold, italic, bold+italic, strike, underline, monospace.
- Added real Telegram-entity preview.
- Added automatic outgoing plain-text formatting handler.
- Dot commands and inline-panel messages are excluded from formatting.
