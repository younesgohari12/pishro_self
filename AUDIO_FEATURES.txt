قابلیت‌های صوتی AvalAI
=====================

STT (از v0.09.19 — زنجیره تأمین‌کننده):
- سرویس مسئول: services/stt_service.py (fallback خودکار + مدارشکن + خطای فارسی)
- اول زنجیره: AvalAI — Endpoint: /v1/audio/transcriptions — Model: AVALAI_STT_MODEL
- پشتیبان‌ها: STT_FALLBACK_PROVIDERS در کانفیگ پایدار (OpenAI-compatible)
  → راهنما: STT_FALLBACK_SETUP_FA.txt
- خطاها: فارسی طبقه‌بندی‌شده (اعتبار/کلید/محدودیت/سرور/...) + راهنمای رفع
- لاگ: [STT] provider=<label> chat=<chat_id> size=<bytes>

TTS:
- API: AvalAI ONLY
- Base URL: https://api.avalai.ir/v1
- Endpoint: /v1/text:synthesize (called through OpenAI SDK client.post)
- SDK: OpenAI Python SDK
- Model: gemini-2.5-flash-tts ONLY
- Output: MP3
- Style: per-user prompt from tts/voices.py
- Fallback: NONE
