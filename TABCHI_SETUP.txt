TABCHI PROFESSIONAL v0.06 — راه‌اندازی
=====================================

1) وابستگی‌ها:
   pip install -r requirements.txt

2) تنظیمات اصلی و کلید AvalAI فقط داخل config.py هستند؛ فایل .env لازم نیست.

3) اجرا:
   python main.py

پنل یکپارچه .پنل
-----------------
در حساب متصل به سلف دستور زیر را بزنید:

  .پنل

گزینه‌ها:
- 🤖 تبچی
- 🎙 تبدیل متن به صوت
- ⚙️ تنظیمات
- 📊 آمار
- ❌ خروج

دکمه 🤖 تبچی با Deep Link مستقیماً صفحه «🤖 مدیریت تبچی» در ربات اصلی را باز می‌کند.
مرحله واسط برای تبچی وجود ندارد.

ساخت بنر
---------
مدیریت تبچی -> ➕ ساخت بنر جدید

ترتیب:
1. محتوا
2. نام
3. مقصد چندانتخابی: گروه‌ها / پیوی‌ها / هر دو
4. فوروارد یا ارسال عادی
5. فاصله به دقیقه
6. پیش‌نمایش و فعال‌سازی

Blacklist
---------
مدیریت تبچی -> 🚫 بلک لیست -> ➕ افزودن

آیدی عددی یا @username/@groupname قابل ثبت است. بلک‌لیست برای هر کاربر جداست
و scheduler قبل از هر ارسال آن را بررسی می‌کند.

رفتار Scheduler
---------------
- هر بنر فعال مستقل زمان‌بندی می‌شود.
- group فقط گروه‌های موجود در Dialogهای حساب را هدف می‌گیرد.
- private فقط پیوی‌های موجود در Dialogهای حساب را هدف می‌گیرد.
- ربات‌ها، Saved Messages و کاربران حذف‌شده از پیوی‌ها کنار گذاشته می‌شوند.
- هیچ auto-join یا پیدا کردن مقصد ناشناس انجام نمی‌شود.
- مقصد blacklist شده با status=skipped_blacklist در send_logs ثبت می‌شود.
- FloodWait باعث defer می‌شود؛ PeerFlood بنر را pause می‌کند.
