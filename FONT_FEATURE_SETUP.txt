MESSAGE FONT FEATURE — v0.08
============================

این نسخه یک گزینه جدید با نام «🔤 فونت» به پنل اصلی دستور .پنل اضافه می‌کند.

مسیر:
.پنل → 🔤 فونت

امکانات:
- 🔤 انتخاب فونت
- 👁 پیش نمایش واقعی با Telegram Entities
- ✅ فعال کردن
- ❌ خاموش کردن

فونت‌ها:
1) Bold / ضخیم
2) Italic / کج
3) Bold + Italic
4) Strikethrough / خط خورده
5) Underline / زیر خط دار
6) Monospace

نکته فنی:
فونت پیام از Telegram Message Entities استفاده می‌کند، نه کاراکترهای فانتزی Unicode.
در نتیجه متن فارسی، انگلیسی و ترکیبی بدون تغییر محتوای اصلی پیام قالب‌بندی می‌شود.

رفتار:
- تنظیمات برای هر user_id جدا ذخیره می‌شود.
- پیش‌فرض قابلیت خاموش است.
- انتخاب پیش‌فرض Bold است.
- پیام‌های دستوری که با نقطه شروع می‌شوند (مثل .پنل) قالب‌بندی نمی‌شوند.
- پیام‌های Inline، پیام دارای keyboard، media caption و پیام‌هایی که از قبل formatting entity دارند دست‌نخورده می‌مانند.
- خاموش بودن master self-bot باعث می‌شود فونت خودکار نیز اجرا نشود.
