سیستم بازی دو نفره الماس
========================

راه‌اندازی:
1) وابستگی‌ها را نصب کنید: pip install -r requirements.txt
2) پروژه را مثل قبل با python main.py اجرا کنید.
3) در ربات اصلی دستور /panel را بزنید.
4) وارد «🎮 مدیریت بازی» شوید.
5) ابتدا گروه اصلی، مالیات، حداقل/حداکثر و زمان انقضا را تنظیم کنید.
6) بازی را فعال کنید و ربات را در گروه اصلی ادمین قرار دهید.

دستورات گروه:
- موجودی
- بازی 100
- شرط بندی 100
- شرطبندی 100

نکات:
- الماس صرفاً اعتبار مجازی داخل ربات است و برداشت نقدی ندارد.
- تمام زمان‌های دیتابیس UTC هستند؛ نمایش موجودی با تاریخ شمسی تهران است.
- مبلغ سازنده هنگام ایجاد بازی رزرو و هنگام لغو/انقضا کامل بازگردانده می‌شود.
- تمام تغییرات موجودی در diamond_transactions ثبت می‌شوند.
- تنظیمات و بازی‌های باز بعد از Restart از SQLite بازیابی می‌شوند.
- Migration خودکار است و جداول و اطلاعات قبلی را حذف نمی‌کند.
